# Web Archiving Community

A collection of community links, resources, related projects, and tools for web archiving.

## ArchiveBox Community

- 💬 Chat with us on our [Public Zulip Server](https://zulip.archivebox.io)
- 🐞 Open an [issue or feature request](https://github.com/ArchiveBox/ArchiveBox/issues?q=is%3Aissue+is%3Aopen+sort%3Aupdated-desc) in our bug tracker
- 💠 Reach out on Twitter [@ArchiveBoxApp](https://twitter.com/ArchiveBoxApp) or [@theSquashSH](https://twitter.com/theSquashSH)
- 🏛️ [Professional support & consulting services](https://docs.sweeting.me/s/archivebox-consulting-services)

## Other Self-Hosted Archiving Tools

- [Wallabag](https://wallabag.org/) — Self-hosted read-it-later service
- [Shiori](https://github.com/go-shiori/shiori) — Simple bookmark manager
- [LinkAce](https://www.linkace.org/) — Self-hosted link archive
- [Reminiscence](https://github.com/kanishka-linux/reminiscence) — Self-hosted page caching
- [Hoarder](https://github.com/hoarder-app/hoarder) — Self-hosted bookmarking app
- [Karakeep](https://karakeep.app/) — Self-hosted bookmark manager with AI tagging

## Web Archiving Resources

- [Internet Archive / Wayback Machine](https://archive.org/web/)
- [IIPC (International Internet Preservation Consortium)](https://netpreserve.org/)
- [awesome-web-archiving](https://github.com/iipc/awesome-web-archiving) — A curated list of web archiving resources
- [WARC specification](https://iipc.github.io/warc-specifications/)
- [Webrecorder](https://webrecorder.net/) — High-fidelity WARC-based archiving
- [Browsertrix](https://browsertrix.com/) — Cloud-based browser archiving
- [pywb](https://github.com/webrecorder/pywb) — Python web archive replay toolkit
- [grab-site](https://github.com/ArchiveTeam/grab-site) — ArchiveTeam's web archiving tool

## Related Browser Extensions

- [ArchiveBox Browser Extension](https://github.com/ArchiveBox/archivebox-browser-extension) — Official ArchiveBox extension
- [SingleFile](https://github.com/gildas-lormeau/SingleFile) — Save a complete web page to a single HTML file
- [WebArchive](https://github.com/dessant/web-archives) — View archived versions of web pages
